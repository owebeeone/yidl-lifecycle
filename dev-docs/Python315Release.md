Lifecycle, Dataclass and Undoable. This member owns only its compatibility,
regenerated consumer base, tests, packaging and release configuration. Astichi and
Cache remain reference-only. Release preparation and immutable tagging use Gearu;
registry upload uses the existing trusted publication workflow.

Target: **0.1.1**, with exact YIDL **0.1.2** after that compiler release passes and
is published. Regenerate using the published selected compiler, review generated
differences, then verify the complete 3.12–3.15 source/publication matrix and
installed distributions. Earlier generated-base acceptance is not evidence of
compatibility with a different compiler tuple.
